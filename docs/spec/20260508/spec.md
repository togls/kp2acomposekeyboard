# kp2acomposekeyboard 键盘布局需求

版本：v0.3  
状态：需求草案  
项目定位：基于 Keepass2Android Plugin API 的现代 Compose 安全输入法

---

## 1. 项目目标

`kp2acomposekeyboard` 是一个独立 Android 输入法应用，同时作为 Keepass2Android 插件使用。

它的核心目标是：

1. 提供简单的字母、数字、符号输入能力。
2. 支持从 Keepass2Android 选择条目。
3. 在输入法键盘中展示当前条目的字段按钮。
4. 用户点击字段按钮后，通过 `InputConnection.commitText()` 输入字段值。
5. 不通过剪贴板传递密码。
6. 不显示敏感字段真实值。
7. 不把敏感字段持久化到磁盘。
8. 支持字段超时清理和手动清理。
9. 键盘整体视觉风格参考 Gboard，支持 Android 动态颜色主题。

本项目不是完整通用输入法，不做拼音、联想词、自动纠错、候选词、词典等复杂功能。

---

## 2. 键盘主布局

键盘包含两种主布局：

1. 默认布局
2. 条目布局

---

## 3. 默认布局

默认布局用于普通字符输入。

默认布局出现条件：

1. 用户尚未选择 Keepass2Android 条目。
2. 用户从条目布局点击 `[切换默认布局]`。
3. 当前条目过期或被清除。
4. 用户取消选择条目后继续保持默认布局。

### 3.1 默认布局结构

```text
┌────────────────────────────┐
│ q w e r t y u i o p         │
│ a s d f g h j k l           │
│ ⇧ z x c v b n m ⌫           │
│ [123] [符号] [空格] [选择条目] [换行] │
└────────────────────────────┘
```

如果当前已经有未过期条目，但用户处于默认布局，则顶部增加提示区：

```text
┌────────────────────────────┐
│ 当前已有条目：GitHub   [切回条目布局] │
├────────────────────────────┤
│ q w e r t y u i o p         │
│ a s d f g h j k l           │
│ ⇧ z x c v b n m ⌫           │
│ [123] [符号] [空格] [选择条目] [换行] │
└────────────────────────────┘
```

### 3.2 默认布局顶部提示区

显示条件：

1. 当前存在未过期的 `KeyboardSession`。
2. 当前主布局是默认布局。

不显示条件：

1. 没有当前条目。
2. 当前条目已超时。
3. 用户手动清除了当前条目。
4. 当前处于条目布局。

顶部提示区内容：

```text
当前已有条目：{entryName}   [切回条目布局]
```

行为规则：

1. 点击 `[切回条目布局]` 后切换到条目布局。
2. 不重新查询 Keepass2Android。
3. 不修改当前条目。
4. 不清除当前条目。
5. 如果条目名过长，应单行省略。

### 3.3 默认布局底部按钮

默认布局底部按钮始终固定为：

```text
[123] [符号] [空格] [选择条目] [换行]
```

不根据当前是否已有条目动态变化。

按钮行为：

| 按钮 | 行为 |
| --- | --- |
| `[123]` | 切换到数字输入模式 |
| `[符号]` | 切换到符号输入模式 |
| `[空格]` | 输入空格 |
| `[选择条目]` | 打开 Keepass2Android 查询 / 选择条目 |
| `[换行]` | 发送 Enter |

即使当前已有条目，`[选择条目]` 也表示重新选择条目。

### 3.4 字母输入模式

字母模式结构：

```text
q w e r t y u i o p
a s d f g h j k l
⇧ z x c v b n m ⌫
[123] [符号] [空格] [选择条目] [换行]
```

要求：

1. 支持基础英文字母输入。
2. 支持大小写切换。
3. 不做联想词。
4. 不做自动纠错。
5. 不做候选词。
6. 不做拼音输入。

行为：

| 按键 | 行为 |
| --- | --- |
| 字母键 | 输入对应字母 |
| `⇧` | 小写 / 大写切换 |
| `⌫` | 删除前一个字符 |

P0 阶段大小写规则：

```text
小写 ↔ 大写
```

暂不要求实现单次大写或 Caps Lock。

### 3.5 数字输入模式

数字模式建议结构：

```text
1 2 3 4 5 6 7 8 9 0
- / : ; ( ) ¥ & @ "
. , ? ! '      ⌫
[ABC] [符号] [空格] [选择条目] [换行]
```

按钮行为：

| 按钮 | 行为 |
| --- | --- |
| 数字键 | 输入对应数字 |
| 标点键 | 输入对应符号 |
| `[ABC]` | 切回字母输入模式 |
| `[符号]` | 切换到符号输入模式 |
| `⌫` | 删除前一个字符 |

### 3.6 符号输入模式

符号模式建议结构：

```text
[ ] { } # % ^ * + =
_ \ | ~ < > € £ $ ·
/ ; : " ' `      ⌫
[ABC] [123] [空格] [选择条目] [换行]
```

按钮行为：

| 按钮 | 行为 |
| --- | --- |
| 符号键 | 输入对应符号 |
| `[ABC]` | 切回字母输入模式 |
| `[123]` | 切换到数字输入模式 |
| `⌫` | 删除前一个字符 |

## 4. 条目布局

条目布局用于展示当前 Keepass2Android 条目字段，并允许用户快速输入字段值。

条目布局出现条件：

1. 用户从默认布局点击 `[选择条目]` 并成功选择条目。
2. 用户在默认布局顶部点击 `[切回条目布局]`。
3. 输入法启动时仍存在未过期的当前条目。

条目布局包含两种字段显示模式：

1. 分页模式
2. 展开模式

---

## 5. 条目布局：分页模式

分页模式是条目布局的默认状态。

### 5.1 分页模式结构

```text
┌────────────────────────────┐
│ 当前条目：GitHub            │
├────────────────────────────┤
│ 固定字段：                  │
│ [Username] [Password] [TOTP]│
├────────────────────────────┤
│ 其余字段：                  │
│ [URL] [Email] [Recovery]    │
│ [切换默认布局] [选择条目] [prev] [next] [全部] [⌫] │
├────────────────────────────┤
└────────────────────────────┘
```

### 5.2 当前条目区域

显示当前条目名称。

示例：

```text
当前条目：GitHub
当前条目：example.com
当前条目：公司 VPN
```

规则：

1. 必须显示当前条目名。
2. 条目名过长时单行省略。
3. 如果没有条目名，显示 `当前条目：未命名条目`。
4. 不显示密码值。
5. 不显示 TOTP 值。
6. 不显示任何字段真实内容。

### 5.3 固定字段区域

固定字段区域只显示以下字段：

1. `Username`
2. `Password`
3. `TOTP`

显示规则：

1. 字段存在才显示。
2. 字段不存在不占位。
3. 显示顺序固定：
   1. Username
   2. Password
   3. TOTP
4. 只显示字段标签，不显示字段值。

行为规则：

| 字段按钮 | 行为 |
| --- | --- |
| `[Username]` | 输入用户名 |
| `[Password]` | 输入密码 |
| `[TOTP]` | 输入一次性验证码 |

安全规则：

1. `Password` 视为敏感字段。
2. `TOTP` 视为敏感字段。
3. 敏感字段按钮不显示真实值。
4. 日志中不能打印字段 value。
5. 字段输入不经过系统剪贴板。

### 5.4 其余字段区域

其余字段区域显示除固定字段之外的其他字段。

包括但不限于：

1. URL
2. Email
3. Recovery
4. Notes
5. Phone
6. Address
7. 自定义字段
8. 其他 KP2A 返回字段

不包括：

1. Username
2. Password
3. TOTP

### 5.5 其余字段分页规则

P0 阶段建议每页显示 3 个字段：

```text
[URL] [Email] [Recovery]
```

分页规则：

1. 其余字段区域高度固定。
2. 不允许字段数量无限撑高键盘。
3. 如果其余字段数量超过每页数量，通过 `[prev]` / `[next]` 翻页。
4. 第一页时 `[prev]` 禁用。
5. 最后一页时 `[next]` 禁用。
6. 字段不足一页时 `[prev]` / `[next]` 禁用或隐藏。
7. 重新选择条目后，页码重置为第一页。
8. 切换到展开模式再切回分页模式时，页码可以保持，也可以重置为第一页；P0 建议重置为第一页。

### 5.6 分页模式底部操作栏

分页模式底部包含：

```text
[切换默认布局] [选择条目] [prev] [next] [全部] [⌫]
```

按钮行为：

| 按钮 | 行为 |
| --- | --- |
| `[切换默认布局]` | 切换到默认布局，保留当前条目 |
| `[选择条目]` | 打开 Keepass2Android，重新选择条目 |
| `[prev]` | 切换到上一页其余字段 |
| `[next]` | 切换到下一页其余字段 |
| `[全部]` | 进入展开模式 |
| `[⌫]` | 删除当前输入框前一个字符 |

---

## 6. 条目布局：展开模式

展开模式用于按顺序显示全部字段。

展开模式不再单独分固定字段区域和其余字段区域，而是把所有字段放入同一个可滚动区域。

### 6.1 展开模式结构

```text
┌────────────────────────────┐
│ 当前条目：GitHub            │
├────────────────────────────┤
│ 按顺序显示全部字段：         │
│ [Username] [Password] [TOTP]│
│ [URL] [Email] [Recovery]    │
│ [Phone] [Address] [Notes]   │
│ [Custom1] [Custom2] ...     │
│ （内部可滚动）              │
├────────────────────────────┤
│ [prev] [next] [收起]         │
│ [切换默认布局] [选择条目] [⌫] │
└────────────────────────────┘
```

> 说明：原始草图中展开模式没有显式 `[收起]`，但为了形成完整状态闭环，P0 建议保留 `[收起]` 按钮。

### 6.2 展开模式字段排序

展开模式按顺序显示全部字段。

推荐排序：

1. Username
2. Password
3. TOTP
4. URL
5. Email
6. Recovery
7. Phone
8. Address
9. Notes
10. 其他自定义字段，保持 KP2A 返回顺序

规则：

1. 字段不存在则跳过。
2. 不存在的字段不占位。
3. 字段按钮只显示字段标签。
4. 敏感字段不显示真实值。
5. 点击字段按钮后输入对应字段值。

### 6.3 展开模式滚动规则

展开模式的字段区域必须内部滚动。

要求：

1. 字段区域高度固定。
2. 字段数量过多时，只滚动字段区域。
3. 整个键盘不能因为字段过多无限增高。
4. 当前条目区域固定显示。
5. 底部操作栏固定显示。
6. 字段区域支持手势滚动。
7. `[prev]` / `[next]` 用于辅助滚动字段区域。

### 6.4 展开模式中的 prev / next

展开模式中的 `[prev]` / `[next]` 不再表示分页，而表示字段区域滚动。

行为：

| 按钮 | 行为 |
| --- | --- |
| `[prev]` | 向上滚动一屏字段区域 |
| `[next]` | 向下滚动一屏字段区域 |

禁用规则：

1. 字段区域已经在顶部时，`[prev]` 禁用。
2. 字段区域已经在底部时，`[next]` 禁用。
3. 字段数量不足以滚动时，两个按钮都禁用或隐藏。

### 6.5 展开模式底部操作栏

展开模式底部包含两行按钮：

```text
[prev] [next] [收起]
[切换默认布局] [选择条目] [⌫]
```

按钮行为：

| 按钮 | 行为 |
| --- | --- |
| `[prev]` | 向上滚动全部字段区域 |
| `[next]` | 向下滚动全部字段区域 |
| `[收起]` | 返回分页模式 |
| `[切换默认布局]` | 切换到默认布局，保留当前条目 |
| `[选择条目]` | 打开 Keepass2Android，重新选择条目 |
| `[⌫]` | 删除当前输入框前一个字符 |

## 7. 布局状态切换规则

### 7.1 初始状态

输入法启动时：

```text
无当前条目：
显示默认布局

有当前未过期条目：
显示条目布局
```

### 7.2 默认布局选择条目

```text
点击 [选择条目]
↓
打开 Keepass2Android
↓
用户选择条目
↓
接收字段数据
↓
保存 KeyboardSession
↓
切换到条目布局
↓
字段显示模式为分页模式
```

### 7.3 默认布局取消选择条目

```text
点击 [选择条目]
↓
打开 Keepass2Android
↓
用户取消
↓
保持默认布局
↓
当前条目不变
```

如果之前没有条目，则仍然没有条目。  
如果之前已有条目，则仍保留旧条目，顶部提示区继续显示。

### 7.4 条目布局切换默认布局

```text
点击 [切换默认布局]
↓
切换到默认布局
↓
保留当前条目
↓
默认布局顶部显示“当前已有条目：xxx [切回条目布局]”
```

### 7.5 默认布局切回条目布局

```text
点击 [切回条目布局]
↓
切换到条目布局
↓
不重新查询 Keepass2Android
↓
不修改当前条目
```

### 7.6 分页模式进入展开模式

```text
点击 [全部]
↓
进入展开模式
↓
按顺序显示全部字段
↓
字段区域内部滚动
```

### 7.7 展开模式返回分页模式

```text
点击 [收起]
↓
返回分页模式
↓
其余字段区域恢复分页显示
```

### 7.8 重新选择条目

```text
点击 [选择条目]
↓
打开 Keepass2Android
↓
用户选择新条目
↓
新 KeyboardSession 覆盖旧 KeyboardSession
↓
切换到条目布局
↓
字段显示模式重置为分页模式
↓
其余字段页码重置为第一页
```

### 7.9 条目超时

```text
当前条目超过自动清理时间
↓
清空 KeyboardSession
↓
如果当前是条目布局，切换到默认布局
↓
如果当前是默认布局，隐藏顶部提示区
```

### 7.10 手动清除条目

P0 建议增加 `[清除条目]` 功能，但不强制在当前布局草图中出现。

行为：

```text
点击 [清除条目]
↓
清空 KeyboardSession
↓
切换到默认布局
↓
隐藏顶部提示区
```

## 8. 按键输入行为

### 8.1 普通字符输入

普通字符输入使用：

```kotlin
currentInputConnection?.commitText(text, 1)
```

适用于：

1. 字母
2. 数字
3. 符号
4. 空格
5. 字段值

### 8.2 删除

删除前一个字符：

```kotlin
currentInputConnection?.deleteSurroundingText(1, 0)
```

### 8.3 换行

发送 Enter：

```kotlin
currentInputConnection?.sendKeyEvent(
    KeyEvent(KeyEvent.ACTION_DOWN, KeyEvent.KEYCODE_ENTER)
)
currentInputConnection?.sendKeyEvent(
    KeyEvent(KeyEvent.ACTION_UP, KeyEvent.KEYCODE_ENTER)
)
```

## 9. 字段分类规则

### 9.1 固定字段

固定字段包括：

1. Username
2. Password
3. TOTP

识别字段时应允许大小写差异，例如：

1. `Username`
2. `UserName`
3. `username`
4. `PASSWORD`
5. `TOTP`
6. `otp`

### 9.2 其余字段

除固定字段之外，全部视为其余字段。

### 9.3 字段按钮显示

字段按钮只显示：

```text
字段名称 / 字段标签
```

不显示：

```text
字段真实值
```

尤其是：

1. Password
2. TOTP
3. Recovery Code
4. Token
5. Secret
6. 自定义敏感字段

## 10. 安全要求

### 10.1 禁止行为

必须禁止：

1. 把密码写入 SharedPreferences。
2. 把密码写入 DataStore。
3. 把密码写入数据库。
4. 把密码写入日志。
5. 把密码写入崩溃上报。
6. 把密码写入剪贴板。
7. 在 UI 上展示密码明文。
8. 在 UI 上展示 TOTP 明文。
9. 在调试日志中打印字段 value。

### 10.2 允许行为

允许：

1. 字段值短时间保存在内存中。
2. 用户点击字段按钮后直接输入到当前输入框。
3. 字段超时后自动清空。
4. 用户手动清空。
5. 新条目覆盖旧条目。

### 10.3 自动清理

P0 默认策略：

1. 默认 60 秒后清理当前条目。
2. 输入法销毁时清理当前条目。
3. 用户手动清理时立即清空。
4. 重新选择条目时覆盖旧数据。
5. 可选：输入 Password 后自动清理当前条目。

---

### 10.4 UI 风格与动态颜色

键盘整体视觉风格参考 Gboard。

要求：

1. 使用简洁、圆角、低干扰的按键样式。
2. 按键间距、圆角、阴影、按压反馈应接近现代 Android 键盘体验。
3. 支持 Material You / Android 动态颜色主题。
4. 在 Android 12 及以上设备上，优先使用系统动态颜色。
5. 在不支持动态颜色的系统上，回退到默认 Material 3 颜色方案。
6. 支持浅色模式和深色模式。
7. 条目字段按钮、普通字符按键、操作按钮应有一致的视觉层级。
8. 敏感字段按钮可以使用更谨慎的视觉样式，但不能显示真实值。

注意：

1. 只参考 Gboard 的现代视觉风格和键盘体验。
2. 不复刻 Gboard 的联想词、滑行输入、语音输入、剪贴板、表情、翻译等复杂功能。
3. 不使用 Gboard 的商标、图标或受版权保护的资源。

## 11. Compose 组件建议

推荐组件拆分：

```text
ui/keyboard/
├─ KeyboardRoot.kt
```

## 14. P0 验收标准

P0 完成时，至少满足以下条件：

1. 未选择条目时，输入法显示默认布局。
2. 默认布局底部按钮始终为 `[123] [符号] [空格] [选择条目] [换行]`。
3. 默认布局可以输入字母。
4. 默认布局可以切换大小写。
5. 默认布局可以输入数字。
6. 默认布局可以输入常用符号。
7. 默认布局支持删除、空格、换行。
8. 点击 `[选择条目]` 可以打开 Keepass2Android 查询 / 选择条目。
9. 用户成功选择条目后，自动切换到条目布局。
10. 条目布局显示当前条目名称。
11. 条目布局分页模式显示固定字段 Username / Password / TOTP。
12. 固定字段不存在时不占位。
13. 条目布局分页模式显示其余字段。
14. 其余字段支持 `[prev]` / `[next]` 翻页。
15. 点击 `[全部]` 后进入展开模式。
16. 展开模式按顺序显示全部字段。
17. 展开模式字段区域内部滚动。
18. 展开模式中的 `[prev]` / `[next]` 用于滚动字段区域。
19. 展开模式点击 `[收起]` 可以回到分页模式。
20. 点击 `[切换默认布局]` 可以回到默认布局，且当前条目不丢失。
21. 默认布局中如果已有条目，顶部显示当前已有条目提示。
22. 点击 `[切回条目布局]` 可以返回条目布局。
23. 点击 `[选择条目]` 可以重新选择条目，并覆盖旧条目。
24. 点击字段按钮可以输入对应字段值。
25. Password / TOTP 不显示真实值。
26. Password / TOTP 不写日志。
27. 字段输入不经过剪贴板。
28. 当前条目超时后自动清理。
29. 当前条目清理后回到默认布局。
30. 字段过多时，键盘整体高度不会无限增大。
31. 键盘整体视觉风格接近 Gboard 的现代 Android 键盘体验。
32. Android 12 及以上支持动态颜色主题。
33. 不支持动态颜色时回退到默认 Material 3 颜色方案。

## 16. 核心原则

1. KISS：优先保持简单、可维护。
2. 不复刻旧 LatinIME。
3. 不实现复杂通用输入法能力。
4. 不通过剪贴板传递敏感数据。
5. 不持久化密码。
6. 不显示敏感字段真实值。
7. 插件逻辑、输入法逻辑、UI 状态分离。
8. 当前版本优先满足自用和基础安全输入场景。
9. 视觉风格参考 Gboard，但不复制其品牌资源或复杂功能。
